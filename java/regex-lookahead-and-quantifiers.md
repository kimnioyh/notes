# 정규식 전방탐색(lookahead)과 수량자가 뭐에 붙나

**한 문장**: `(?=...)`는 위치를 소비하지 않고 조건만 검사하는 "너비 0" 검사이고, `*`/`+` 같은 수량자는 **바로 앞의 한 토큰에만** 붙는다.

## 왜 헷갈렸나
비밀번호 정규식 `^(?=.*[A-Za-z])(?=.*\d).+$`에서:
- "`*`가 0개 이상이면, 저 안의 조건(`[A-Za-z]`)은 필요 없는 거 아냐?" ← 여기서 막혔다.

## 핵심
**수량자는 바로 앞 토큰에만 적용된다.** `.*`에서 `*`는 `.`(아무 문자)에만 붙고, 뒤의 `[A-Za-z]`에는 **안** 붙는다. `[A-Za-z]`는 수량자가 없으니 **정확히 1개, 필수**.

**전방탐색 `(?=X)`** = "지금 위치 기준 앞쪽이 X와 매칭되나?"만 검사하고 **문자를 소비하지 않는다**(너비 0). 그래서 `(?=.*[A-Za-z])(?=.*\d)`처럼 여러 개를 **같은 시작 위치**에서 각각 검사할 수 있다.

- `(?=.*[A-Za-z])` = "어딘가에 영문자 1개 이상 있다" → **영문 필수**
- `.*`의 역할 = 그 영문자가 **맨 앞이 아니어도** 되게 앞을 건너뛰는 패딩. (`.*` 빼고 `(?=[A-Za-z])`면 "첫 글자가 영문"이라 너무 빡셈)
- 실제 문자 매칭·길이는 뒤의 `.+`(1개 이상 아무 문자)가 담당. 길이 8~32는 보통 `@Size`가 따로 처리.

**결론**: `*`가 조건을 없애는 게 아니라, `[A-Za-z]`(필수 조건)는 그대로 살아있고 `.*`는 "위치 자유"만 준다.

## 예시 코드
```java
// 영문+숫자 각 1자 이상 필수, 그 외(특수문자 등)는 허용
@Pattern(regexp = "^(?=.*[A-Za-z])(?=.*\\d).+$")   // 자바 문자열이라 \d 는 \\d
```
동작 (입력 `123a`):
- `(?=.*[A-Za-z])`: `.*`가 `123` 먹고 → `[A-Za-z]`가 `a` 매칭 ✅
- 입력 `1234`: 어디를 봐도 영문자가 없어 lookahead 실패 → 거부 ✅

| 비번 | 통과? | 이유 |
|---|---|---|
| `abc12345` | ✅ | 영문+숫자 |
| `pa$$w0rd` | ✅ | `$`는 `.`가 받음 |
| `abcdefgh` | ❌ | 숫자 없음 |

## 확인 문제
1. `.*[A-Za-z]`에서 `*`는 무엇에 붙나? `[A-Za-z]`는 몇 개 매칭되나?
2. `(?=X)`가 "너비 0"이라는 게 왜 여러 lookahead를 이어 쓸 수 있게 해주나?

<details><summary>답</summary>

1. `*`는 바로 앞 `.` **하나에만** 붙어 "아무 문자 0개 이상". `[A-Za-z]`는 수량자가 없으니 **정확히 1개, 필수**.
2. lookahead는 조건만 확인하고 **문자를 소비(위치를 전진)하지 않기** 때문에, 여러 개를 **같은 시작 위치**에서 각각 독립적으로 검사할 수 있다. `(?=.*[A-Za-z])(?=.*\d)` = 같은 자리에서 "영문 있나?" "숫자 있나?"를 둘 다 검사.

</details>
